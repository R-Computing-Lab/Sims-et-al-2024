#  Supporting Code for Exploring the relationship between depression and delinquency: A sibling comparison design using the NLSY

This code contains all the analyses (and then some) for the following paper by Sims, Trattner, and Garrison (2024).

Sims, E. E., Trattner, J. D., & Garrison, S. M. (2024). Exploring the relationship between depression and delinquency: a sibling comparison design using the NLSY. Frontiers in psychology, 15, 1430978. https://doi.org/10.3389/fpsyg.2024.1430978
